## Mô tả
Hệ thống quản lý thư viện và mượn trả sách, phục vụ hai nhóm người dùng: Admin và Độc giả.

## Công nghệ sử dụng
- .NET 10 SDK
- ASP.NET Core 10 MVC
- Entity Framework Core 10
- SQL Server
- Git/GitHub

## Hướng dẫn cài đặt
1. Clone repository này về máy.
2. Mở Solution bằng Visual Studio 2026.
3. Cập nhật chuỗi kết nối SQL Server trong `appsettings.json`.
4. Chạy Migration: `Update-Database`.
5. Nhấn F5 để chạy chương trình.
